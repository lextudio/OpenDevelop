## Open: macOS bundle verification crash (blocks a green four-platform draft)
`od.build-solution` kills the packaged app on the macOS runner, intermittently (beta.3, beta.6 and
beta.15 passed). The diagnostics added in `build/macos/verify-application-bundle.sh` captured the
stack:

```
System.Threading.Mutex.CreateMutexCore  ->  NuGet.Settings.ExecuteSynchronized
  -> NuGet.Settings.LoadDefaultSettings -> NuGet.ProxyCache..cctor
  -> NuGet.RedirectedHttpClient.EnsureClient
```

So a NuGet settings read (named-mutex synchronisation) throws during the build and the process dies
unhandled. Fix: make the build path's NuGet settings/proxy-cache initialisation tolerate a failing
named mutex (or catch at the `od.build-solution` handler so a failure is an error response, not a
dead IDE). Reproduce by running the bundle verification on a macOS machine with the same
`~/.nuget` state.
