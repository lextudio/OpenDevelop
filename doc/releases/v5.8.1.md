* Keyboard shortcuts can be changed (#26): Tools > Options > Keyboard lists every command with its shortcut. Search by name or press a chord to see who owns it, give a command a shortcut (Clean has none by default), change or remove one, and resolve conflicts with a reassign. Changes apply when you press OK, survive a restart, and can be exported and imported.
* Break on an exception stops on the line that threw instead of in code you did not write (#27).
* When the debugger stops in code that has no source or debug information, such as a stack frame inside a library, that frame opens as decompiled source in the editor. It is part of the ILSpy add-in and is off when that add-in is disabled.
* The Add-in manager can suspend an add-in and resume it later. A suspended add-in stays suspended after a restart until you resume it.
* The Options dialog opens larger, and the icons in its tree no longer sit on the expand and collapse arrows.
