* **Workspace Trust (Restricted Mode).** Opening a solution from a folder you have not trusted now asks first. In Restricted Mode OpenDevelop only edits text with basic syntax highlighting: no build, run, debug, tests, designers, terminals, code completion or third-party analyzers. Trust is remembered per folder, and Tools > Workspace Trust shows the list and can revoke it.
* The Workspace Trust UI and messages are available in English, Simplified Chinese and Traditional Chinese.
* LibreWPF, LibreWinForms and ProGPU updated to `0.1.0-preview.69.70.1`.
* SharpDbg updated to a build that follows the debuggee's requests instead of polling.
* XAML breakpoints and navigation now land on the right file when generated code uses escaped `#line` paths.
* Fixes: the Error List no longer keeps stale entries after a solution is reopened, ILSpy search no longer leaks handlers, key binding overrides apply on each owner's dispatcher, and a missing `SharpTreeNodeView` no longer crashes the designer.
