* The Help menu now links to OpenDevelop's own GitHub, releases, issues, contributing, third-party notices, sponsor page, and the upstream projects it is built on (AvalonEdit, AvalonDock, ILSpy, LibreWPF, SharpDbg); the obsolete SharpDevelop ReadMe entry is gone.
* Menu items no longer rebuild their children when a nested submenu opens, fixing flicker and stale entries in multi-level menus.
* Android SDK Manager: package listing, checkbox toggles, and the `--install` call now work on Windows by running `sdkmanager` through `cmd.exe`, and an empty package tree no longer crashes the view. The package tree is ordered by level and family, auto-discovers the SDK, and shows a busy indicator while loading.
* A single Device Manager is available on every platform, with localized strings and SDK auto-discovery.
* The About dialog is restyled for dark themes and localized, and the BusyIndicator overlay is themed and shared across the remaining async-loading views.
* ComboBox templates gained an editable text box in both themes, and the implicit ListViewItem style that SharpGridView's container style is based on is now defined.
* All built-in add-ins now carry the IDE's product version, and add-in manifests that named the wrong assembly are corrected, so add-ins load reliably.
* The product version stays at the tag value between releases instead of drifting.
* LibreWPF is upgraded to `0.1.0-preview.69.58.1`.
* macOS and Windows UI labels that were still in English are now localized.
