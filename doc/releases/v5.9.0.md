* OpenDevelop now runs on .NET 11 across the shell, add-ins and designer child hosts, while preserving .NET 10 project compatibility. New projects target .NET 10 by default, and templates that expose a Framework choice can explicitly create a .NET 10 project.
* The debugger now uses the .NET 11 SharpDbg adapter and adds an end-to-end journey for modern async debugging. Existing .NET 10 fixtures, including x86 debugging on Windows, remain supported.
* The XAML designer keeps selections synchronized between the canvas, Outline and code editor. A caret move in the code editor intentionally does not select a design element.
* The WinUI designer gains a live design-time `{x:Bind}` evaluator, a Live Bindings toolbar toggle, richer Outline and Properties information, and tested move, resize and toolbox editing journeys.
* The project Options application page no longer clips long output names, and the XAML language-service completion binding is restored.
