* Manage NuGet Packages is rebuilt: installs, updates and removals run in the background, and a package shows its deprecation and vulnerability warnings.
* The editor light bulb offers Roslyn quick fixes and refactorings, and can install a package for a missing namespace.
* A Device Manager lists, creates, starts and stops Android emulators and iOS simulators.
* The Uno designer previews XAML on an iOS Simulator or an Android emulator, with a device frame and rotation.
* F5 debugs .NET 11 Android apps on a device and iOS apps in the Simulator.
* A machine without .NET SDK 10 says so at startup instead of failing every project (#21).
* Builds use only the SDK chosen in Tools > Options > .NET SDK, and discovery stops at .NET SDK 10.
* Only WPF XAML opens in the WPF designer, so Uno and WinUI documents reach their own Design view.
* Projects can be renamed and deleted in the Project Browser again (#24); MewUI and GTK files nest under their root.
* The GTK designer gains notebook actions, stateful menus, reloadable custom widgets and composite templates.
* The editor contract packages are built from MIT sources, and the Toolkit for WPF licence ships in SOURCE-LICENSES.
* Designer property edits run in the background so the UI stays responsive.
