* Manage NuGet Packages is rebuilt on NuGet's own configuration and protocol: install, remove and update run asynchronously through one gate with a progress bar that locks the dialog, PackageReference nodes gain Update, the Packages folder has its own context menu, and central versions are written to Directory.Packages.props instead of the project. Selecting a package now shows that exact version's deprecation reasons, the author's message, the recommended alternative and every known vulnerability with its advisory link.
* The editor light bulb gains Roslyn quick fixes and refactorings for C# and Visual Basic, offers "Install NuGet package" for an unresolved namespace (CS0246 and CS0234), and suggests only packages the solution already references, so it no longer searches a feed per caret stop. Its popup no longer crashes or draws off-screen.
* A Device Manager window, shared by every designer, lists the machine's Android emulators and iOS simulators with their state and can start, stop, hide, create and delete them; the designers' device picker links to it.
* The Uno designer previews XAML in an iOS Simulator or an Android emulator: it picks a device per project, draws a device frame, rotates it, can cancel a start that is still booting, and shows a four-step progress card for the device, host, connection and first frame. The mobile hosts ship beside the desktop head.
* F5 debugs net11.0-android projects on a selected adb device and net11.0-ios projects in the iOS Simulator, deploying the bundled NativeAOT agents, attaching SharpDbg and cleaning up its per-session port, token and debug-app setting. Debug > Android Device and Debug > iOS Simulator pick the target.
* A machine without a usable .NET SDK 10 now learns that when the workbench opens: the IDE shows the same check the Build pad reports, in a copyable dialog that names the install command, and exits instead of opening a session in which every SDK-style project fails with "The SDK 'Microsoft.NET.Sdk' specified could not be found" (#21).
* Project builds, restores and designer builds use only the SDK selected in Tools > Options > .NET SDK, falling back to the SDK that started the session, and honour a project's global.json pin within that root. Automatic discovery now stops at .NET SDK 10, so a newer major is offered only after it is added under that option, and MSB4216 gets an explanation instead of a bare diagnostic.
* Only WPF and unknown XAML open in the WPF designer now, so an Uno or WinUI document reaches its own Design view instead of starting the LibreWPF one first, and the WindowClone preview frame keeps a stable neutral chrome on hosts that do not map the Windows caption colours.
* Projects can be renamed and deleted from the Project Browser again (#24); MewUI pages appear in the tree with their code-behind nested, and a GTK design's `.ui`, `.ui.cs` and `.css` files nest under the `.ui` markup that is their root.
* The GTK designer gains notebook action widgets, `app.*` action menus with state, custom-widget assemblies that are reloaded when they are rebuilt, composite templates resolved across the solution, and a `requires` code action when libadwaita is missing.
* Editor contracts are now built from the MIT `vs-editor-api` sources instead of the Visual Studio-only packages, non-redistributable packages stay out of the payload, and the Toolkit for WPF fork's Ms-PL text ships in `SOURCE-LICENSES`.
* Forms, WPF, GTK and MewUI property edits run asynchronously so the UI stays responsive, and a WPF DevFlow event binding reports success only after the code-behind handler has been created.
