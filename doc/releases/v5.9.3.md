* Items of an open menu popup (for example the Tools menu) show their hover highlight again on macOS. A popup that is its own native window kept presenting its first frame after its content changed, because its render requests never reached its own window host.
* A message box opened from inside a dialog (for example a Yes/No confirmation in Options) closes as soon as it is answered instead of staying on screen until the outer dialog ends.
* Linux needs Ubuntu 26.04 (glibc 2.43) or newer, on both x64 and ARM64: the native renderer library is built on that image and does not load on older distributions. [LINUX.md](https://github.com/lextudio/OpenDevelop/blob/master/LINUX.md) lists the details. CI and the release build now run on the same images.
* The LibreWPF, LibreWinForms and ProGPU packages are taken at `0.1.0-preview.69.57.1`: every publish of that closure now has its own version number instead of republishing `0.1.0-preview.69`.
