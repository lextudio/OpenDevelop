* XSG projects now support debugging XAML: breakpoints on XAML lines (via the generator's `#line` directives), expression breakpoints, and step into/over from an expression breakpoint, with a "View Generated Code" command in the XAML editor's context menu.
* The XAML editor exposes generated sources over the Roslyn host protocol, so generated code can be inspected and navigated.
* Generator diagnostics from additional files are reported on the XAML line instead of being lost.
* The XAML source generator follows MAUI's C# expression syntax for LibreWPF XSG.
* The XSG status is shown in the status bar, and an `od.wpf-designer.xsg-status` DevFlow action reports it.
* SharpDbg is moved to `1.0.0-lextudio.45727785139.1`, adding `#line` breakpoint cases.
* `DapSession.Stop` teardown is bounded so a stuck cleanup can no longer freeze the IDE.
* The GC-heap assertions in the performance tests now check the peak heap size and require non-zero gen-0 collections per interval.
* CI: a failed optional additional build is no longer fatal, and the entry that deletes `progpu.native.sdk` files is named.
* Re-pushing a release tag now replaces the existing draft instead of leaving a duplicate.
