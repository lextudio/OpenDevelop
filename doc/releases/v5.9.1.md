* The AddIn Manager now finds, installs and updates add-ins from GitHub Releases instead of the NuGet gallery. Add the `owner/repo` of an add-in author you trust in **Tools > Options > AddIns > Trusted repositories**; each release tagged `vMAJOR.MINOR.PATCH` that carries one `.odaddin` asset is then listed under Available and Updates. Downloads are verified against the release's SHA-256 digest, only public repositories are read (no GitHub token is used or stored), and only the five newest releases of each repository are considered. Breaking: the NuGet gallery and the `.sdaddin` and `.zip` add-in formats are no longer supported.
* The Addin SDK gains a `PackOdAddin` target that builds an add-in's `.odaddin` package, and the Windows distribution ships the SDK so a publishing machine with OpenDevelop installed can build it.
* An instance started with `-configdir:` now says that it cannot install add-ins instead of failing with a null-path error.
* The WinUI designer uses the Surface host by default and no longer falls back to another host. It requires Uno 7, adds live `{x:Bind}` previews, remembers the Live Bindings choice across documents and sessions, lets a converter declare its own settings, and fills the Tools pad from the static catalog before the host starts.
* Remaining UnoDevelop references were removed from the source, configuration and technotes.
