## Initial Integration Blocker

All 209 integration tests fail before their test bodies run because the shared
`OpenDevelopAppFixture` cannot start OpenDevelop. The process exits with signal 6
while `ProGpuWpfSdkPortableBootstrap` initializes:

```text
System.IO.FileNotFoundException: Could not load file or assembly
'System.Drawing.Common, Version=10.0.0.0, Culture=neutral,
PublicKeyToken=c29c9752855ee183'
```

The canonical `LibreWinForms.ProGPU` backend references `System.Drawing.Common`
version `10.0.0.0`, but OpenDevelop's portable output deploys and declares only
`ProGPU.System.Drawing.Common` (assembly version `0.0.0.0`) in `OpenDevelop.deps.json`.
The physical file is present, but CoreCLR rejects it because the declared assembly
identity does not match. This is one package/runtime deployment defect, not 209
independent test regressions.

The integration test prerequisite build completed successfully with 883 warnings
and no errors. Existing warning sources include nullable annotations, analyzers,
and the `System.Security.Permissions` 9.0.0.0/10.0.0.0 assembly conflict.

## Strict Geometry Clip Repair

The strict source hit-test path intentionally prohibits a bounds fallback. Its
failure diagnostic identified a deferred combined geometry with no direct
figures. The exact path compiler successfully resolved that combination to an
empty result, but the hit-test cache represented both an empty result and an
unavailable encoding as `false`. The source capture path therefore threw instead
of applying the exact empty clip.

`GpuRenderCommandHitTestCacheBuilder.PushGeometryClip` now treats a
zero-segment result from the exact compiler as `ClipState.Empty`: descendants
publish no hit geometry. Non-empty paths that cannot be exactly encoded still
throw; no bounds fallback was introduced. The ProGPU regression project now
includes `EmptyCombinedSourceGeometryClipSuppressesInputWithoutBoundsFallback`.

Validation was intentionally kept to one formal integration test after the
repair:

```text

Total: 1; Failed: 0; Skipped: 0
```

The same app fixture completed startup, and the latest application log reached
`dockingManager_Loaded` without a source-geometry clip exception. The temporary
`WinUIGalleryProbe` is not a passing-test target because it unconditionally
fails after writing diagnostics; without its opt-in environment variables it is
reported as skipped. The historical full 209-test result remains unchanged and
has not yet been rerun.
